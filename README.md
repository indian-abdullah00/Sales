# Sales Library: The Best Pitches, Dialogues and Frameworks

A collection of the best material on sales pitches, conversations and frameworks, with most of the weight on **software (B2B/SaaS)**. It also pulls in other fields (negotiation, persuasion science, investor pitching, keynotes, transactional sales) so you see more than one point of view.

Each resource has its own markdown file in the same format: what it is, why it made the cut, the core ideas, **the actual dialogue and scripts**, how to use it, and links to the original.

> Start with [`00-synthesis/how-it-all-fits-together.md`](00-synthesis/how-it-all-fits-together.md). It shows where the sources agree, where they disagree, and how they fit into one call flow.

## Evidence tiers

Every resource is tagged so you know how much weight to give it:

| Tier | Meaning |
|---|---|
| **A: Data-backed** | Based on large-sample analysis of real calls, emails or deals |
| **B: Proven at scale** | A framework adopted by whole industries, with a documented record of results |
| **C: Expert practitioner** | Top performers' playbooks; strong, but based on experience rather than data |
| **D: Study, don't copy** | Useful for understanding tactics, but ethically risky or out of date |

## A note on copyright
This library holds **notes, structures, short quotes and original example scripts built on each framework**, and links to every original. Full books and paid courses are not copied here; follow the links to read or buy the originals. Example scripts that were written for this library, rather than quoted from a source, are labeled *illustrative*.
